# 🌱 Skillfolk – Skill Exchange Platform

**Learn Together. Share Knowledge. Grow Together.**

Skillfolk is a community-driven web application that encourages people to exchange knowledge and skills without monetary transactions. Users can discover new skills, share their expertise, and connect with others who are interested in learning.

The idea is simple: teach what you know and learn what you don't.

## ✨ Features

- **Skill Discovery:** Browse available skills across different categories.
- **Search & Filtering:** Find skills using keywords, categories, and learning formats.
- **User Authentication:** Register and log in to your account.
- **Skill Sharing:** Add your own skills and share your expertise with the community.
- **Personal Dashboard:** Manage your profile and view your shared skills.
- **People Discovery:** Explore community members, their interests, and their skills.
- **Saved Skills:** Save interesting skills for later.
- **Profile Management:** Customize your name, location, and personal bio.
- **Theme Customization:** Switch between light and dark modes and customize the interface colors.
- **Responsive Design:** User-friendly interface designed for different screen sizes.

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Edge, etc.).
- A code editor such as Visual Studio Code.
- VS Code Live Server extension (optional).

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/MahmoudAmer0a/Skill-Exchange.git
```

**2. Navigate to the project directory**

```bash
cd Skill-Exchange
```

**3. Run the application**

Open `index.html` directly in your browser, or use the Live Server extension in VS Code.

No additional dependencies or package installations are required.

## 💾 Data Storage

The application currently uses browser LocalStorage to maintain client-side data, including:

- User accounts and session information.
- User-created skills.
- Saved skills.
- Application preferences and theme settings.

**Note:** This is a frontend application prototype. Data is stored locally in the browser rather than in a centralized backend database. Sample community members and skills are provided within the application.
